# GeoTIFF NDVI externos

Los GeoTIFF NDVI están almacenados externamente y no forman parte de este proyecto.

La ubicación se controla mediante la variable de entorno TESIS_NDVI_ROOT. Si no está definida, se usa D:\GeoTIFF NDVI.

Esta carpeta está vacía intencionalmente. Los GeoTIFF no deben copiarse al proyecto ni al repositorio.
